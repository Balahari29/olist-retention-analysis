# Seller scorecard: manual steps in Excel for Mac (Microsoft 365)

`seller_scorecard.xlsx` is generated by `src/build_seller_scorecard.py` from `seller_scorecard_data.csv`
(625 sellers with 30+ delivered orders, exported from the MySQL view `v_seller_scorecard` by `src/export_views.py`).
Three things need Excel's own interface, so you do them by hand: a refreshable Power Query connection, a
PivotTable with a slicer, and a What-If Data Table.

> Menu names below are from Excel for Mac (Microsoft 365). If a label differs slightly in your version, look for the
> same word in the **Data** or **PivotTable Analyze** ribbon tab.

**Before you start:** open `seller_scorecard.xlsx`. If a yellow bar says the file came from the internet or is in
Protected View, click **Enable Editing**. Excel recalculates every formula on open (the file is saved with
"recalculate on load"), so all values appear after a second.

---

## Step 1: Connect the CSV with Power Query (so the data refreshes)

**What and why, in plain words:** the `Data` sheet in the file is a snapshot. Power Query creates a **connection** to
the CSV file instead: when the SQL is rerun and the CSV is exported again, one click on **Refresh** pulls in the new
numbers. No copy-paste, so no copy-paste mistakes.

1. Go to the **Data** tab → click **Get Data (Power Query)**.
2. In *Choose data source*, click **Text/CSV**.
3. Click **Browse…**, go to `olist-retention-analysis/excel/`, select **`seller_scorecard_data.csv`**, click **Get Data**, then **Next**.
4. A preview appears. Click **Transform Data** to open the Power Query Editor (so you can check the types).
5. In the editor, check the data type icon on each column header:
   - `seller_id`, `seller_city`, `seller_state` → **Text** (ABC icon). If `seller_id` shows a number icon,
     click the icon → **Text**. IDs are labels, never numbers.
   - `delivered_orders`, `late_orders`, `excess_late_rank`, `late_rate_rank`, `late_rate_decile`,
     `reviewed_orders`, `review_score_sum` → **Whole Number**.
   - `late_rate_pct`, `excess_late_orders`, `avg_review_score`, `revenue_brl` → **Decimal Number**.
6. In the right-hand *Query Settings* pane, rename the query to **`SellerScorecard`**.
7. Click **Close & Load** ▸ **Close & Load To…** → choose **Table** and **New worksheet** → **OK**.
   Excel adds a sheet with a green-striped table named `SellerScorecard`.
8. Rename that sheet (double-click the tab) to **`Data_PQ`**.

**To refresh later:** rerun `.venv/bin/python src/run_analysis.py` and `.venv/bin/python src/export_views.py`, then in
Excel click **Data** → **Refresh All**.

*Interview line:* "I load the CSV through Power Query rather than pasting it, so the scorecard refreshes with one
click and the data types (IDs as text, counts as whole numbers) are set once in the query, not fixed by hand each time."

**Optional (point the scorecard at the live data):** the Scorecard and KPI formulas read the snapshot sheet `Data`.
To make them read `Data_PQ` instead: press **⌘ + Shift + H** (Find & Replace) → *Find what* `Data!` → *Replace with*
`Data_PQ!` → *Within*: **Workbook**, *Look in*: **Formulas** → **Replace All**. The formula ranges cover 625 rows
(rows 2-626); if a refresh changes the number of sellers, rebuild the workbook with `src/build_seller_scorecard.py`
or extend the ranges.

## Step 2: PivotTable of late % by state, with a decile slicer

**What and why:** a PivotTable groups the 625 sellers by state and adds up their orders. The slicer is a row of
buttons that filters the PivotTable, e.g. to see only the worst 10 % of sellers (decile 1).

1. Click any cell inside the `SellerScorecard` table on `Data_PQ` (or inside the table on `Data` if you skipped Step 1).
2. **Insert** tab → **PivotTable** → the table name is filled in → choose **New Worksheet** → **OK**.
3. In the *PivotTable Fields* pane, drag:
   - `seller_state` → **Rows**
   - `delivered_orders` → **Values** (shows *Sum of delivered_orders*)
   - `late_orders` → **Values** (shows *Sum of late_orders*)
4. Add the late % as a **calculated field** (it divides the *sums*, not the per-seller percentages):
   **PivotTable Analyze** tab → **Fields, Items & Sets** → **Calculated Field…** →
   *Name:* `Late %` → *Formula:* `= late_orders / delivered_orders` → **Add** → **OK**.
5. Format it: click any *Sum of Late %* value → right-click → **Value Field Settings…** → **Number Format** →
   **Percentage**, 2 decimals → **OK**. Rename the column header to `Late %` if you like.
6. Sort: click any *Late %* value → right-click → **Sort** → **Sort Largest to Smallest**.
7. Add the slicer: click inside the PivotTable → **PivotTable Analyze** → **Insert Slicer** → tick
   **`late_rate_decile`** → **OK**. Click **1** to see only the worst-decile sellers; click the filter-clear icon
   on the slicer to see all again.

*Interview line:* "Late % by state is a calculated field, sum of late orders divided by sum of delivered orders, so big
sellers count in proportion to their volume. Averaging each seller's percentage would give a seller with 30 orders the
same weight as one with 1,700."

## Step 3: What-If Data Table over a 10-50 % reduction in late orders

**What and why:** the `What-If` sheet answers one question for one input (cell **B3**, "% reduction in late
orders"). A **Data Table** reruns that whole calculation for several input values at once (10 %, 20 %, … 50 %) and
lays the answers out as a table. Nothing is copied: Excel substitutes each value into B3 behind the scenes.

The sheet is already laid out for it:
- **A27:A31** hold the input values 10 %-50 %.
- **B26:E26** hold formulas pointing at the results (rise in review LOW/HIGH, new average LOW/HIGH).

1. Go to the **What-If** sheet and select **A26:E31** (the formula row on top, the input values on the left).
2. **Data** tab → **What-If Analysis** → **Data Table…**
3. Leave *Row input cell* **empty**. In *Column input cell* click cell **B3** (it shows `$B$3`). Click **OK**.
4. B27:E31 fill with `{=TABLE(,B3)}` results. Select B27:E31 → format as **Number**, 3 decimals.
5. If the table does not update when you change inputs: **Formulas** tab → **Calculation Options** →
   **Automatic** (not "Automatic except for data tables").

*Interview line:* "The LOW and HIGH come from my hypothesis test: 0.76 stars per late order if we count only reviews
written after delivery, 2.02 if we count all reviews. Showing a range instead of one number is honest about that uncertainty."

## How the workbook's formulas work (for questions about the file)

| Where | Formula (row 6 shown) | What it does |
|---|---|---|
| Targets!B7 | `=B5/B6` | Late-rate target = platform late orders ÷ delivered orders (6,531 / 96,201): an **assumption** that "average" is the bar |
| Scorecard!B6:D6, G6, M6 | `=_xlfn.XLOOKUP($A6, Data!$A$2:$A$626, Data!$C$2:$C$626)` | Finds the seller's row by ID and returns one column. `_xlfn.` is how the file stores functions newer than Excel 2007; Excel shows plain `XLOOKUP` |
| Scorecard!E6 | `=IF(C6=0,"",D6/C6)` | Late rate = late ÷ delivered |
| Scorecard!F6 | `=IFERROR(XLOOKUP(…review_score_sum…)/XLOOKUP(…reviewed_orders…),"")` | Exact average review (sum ÷ count), not a rounded average |
| Scorecard!H6 | `=D6-C6*J6` | **Excess late orders:** late orders above what an average seller of the same size would have |
| Scorecard!I6 | `=_xlfn.RANK.EQ(H6,$H$6:$H$630,0)` | Rank by excess late orders, 1 = most excess |
| Scorecard!J6, K6 | `=_xlfn.XLOOKUP("Late-rate target", Targets!$A$5:$A$10, Targets!$B$5:$B$10)` | Pulls targets by **name**, so moving rows on Targets does not break anything |
| Scorecard!L6 | `=IF(OR(E6>=J6*2x, F6<3.5),"Action", IF(AND(E6<=J6, F6>=K6),"On target","Watch"))` | Status (thresholds also looked up from Targets) |
| Scorecard!E3 | `=_xlfn.PERCENTILE.INC($E$6:$E$630,0.9)` | Bottom-10 % cut-off: the 90th percentile of late rate; rows at or above it are shaded orange (conditional formatting) |
| What-If!B16 | `=B13/B6*B9` | Rise in average review = (late orders avoided ÷ delivered orders) × stars lost per late order |
| KPI tiles | `=SUM(late)/SUM(delivered)`, `=SUM(review sum)/SUM(reviewed)` | Weighted totals, matching `outputs/seller_scorecard_totals.csv` |

**Verified:** recalculated with a formula engine. 0 formula errors; the KPI tiles equal
`outputs/seller_scorecard_totals.csv`; every seller's late rate, excess late orders and excess rank match the SQL
export; the orange bottom-10 % rows are the same 63 sellers as SQL's worst `NTILE` decile.
